# WatchAll project instructions

## Implementation log (required)

After completing any major fix, feature, or change in this project, before finishing the response or thread:

1. Append a new entry to `docs/IMPLEMENTATION_LOG.txt`. Never overwrite or remove older entries.
2. Write in plain, human-readable English that a non-developer can understand. Keep it brief but complete.
3. Include:
   - Date
   - Area (for example: Search, Video player, Stream extraction)
   - The issue or feature
   - What was changed and how it works now
   - Files affected
   - How it was verified
4. Do not log small cosmetic edits, experiments, or ideas that were not implemented.
5. If `docs/IMPLEMENTATION_LOG.txt` does not exist, create it.
